# DATABASE

This folder will contain:

- `schema.sql` – database schema exported from MySQL (or generated from the Laravel migrations)
- `sample-database-data.sql` – sample data for testing and the demo
- ERD / database design files

Planned main tables: `users`, `categories`, `products`, `product_images`, `carts`, `cart_items`,
`orders`, `order_items`, `coupons`.
